视频获取助手

只在播放页出现「获取视频」，先预览、再下载，所有处理都在本机完成。

v1.0.0

通用网站支持

让任意视频网页出现「获取视频」按钮

读取中…

抖音、快手、哔哩哔哩与本地测试页默认启用。其他网站需要你主动授权后才会注入按钮，扩展不会默认读取所有网站的页面。

不授权也能用 在任意网页点击浏览器工具栏的扩展图标，可通过 activeTab 临时向当前标签页注入按钮；刷新页面后失效。

权限说明

为什么需要这些权限

downloads

把最终 MP4 保存到浏览器下载目录，并读取下载进度、取消中断的下载。

storage

使用 storage.session 保存任务元数据。临时媒体分片保存在本机 IndexedDB，完成后清理。

scripting + activeTab

在用户点击工具栏图标时向当前标签页注入按钮；以及在授权通用网站后动态注册内容脚本。

offscreen

Service Worker 没有 DOM 且可能被回收。HLS/DASH 解析、ffmpeg.wasm 转封装和 Blob 下载地址必须在 offscreen 文档中完成。

declarativeNetRequest

仅当媒体服务器要求防盗链 Referer 时，为当前任务涉及的媒体域名添加临时会话规则，任务结束立即移除。

alarms

每 5 分钟清理过期任务、临时分片和 DNR 会话规则，避免残留数据占用空间。

站点权限

默认只包含抖音、快手、哔哩哔哩及其公开 CDN 域名，以及 localhost / 127.0.0.1 测试地址。

可选全站权限

仅在你点击上方按钮并确认 Chrome/Edge 权限弹窗后授予。可随时关闭。

隐私与合规

不上传、不记录敏感地址

  • 视频、媒体地址、签名参数和页面内容只在本机处理，不发送到任何第三方服务器。
  • 不伪造 Cookie、不读取登录凭证、不破解会员 / 地区限制 / DRM / 去水印。
  • 日志中的完整媒体 URL 会被脱敏；临时分片在完成、取消或过期后清理。
  • 仅处理你有权保存的公开、非 DRM 内容，并遵守平台服务条款与著作权法。
